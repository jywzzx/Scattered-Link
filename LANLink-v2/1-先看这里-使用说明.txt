本程序将不同网络环境下的设备接入同一虚拟局域网，
各成员可相互访问并使用对方的虚拟 IP 地址进行游戏联机。

────────────────────────────────────────────────────────────
 一、安装与首次运行
────────────────────────────────────────────────────────────

一、解压
  右键单击 zip 文件并选择「解压到当前文件夹」。
  请勿直接双击压缩包内的可执行文件。

二、启动
  双击 LANLink.exe
  若系统请求管理员权限，请选择「是」。
  创建虚拟网卡需要此权限，整个程序仅提示一次。

三、安全软件
  若安全软件提示拦截，请选择「允许」，并将整个程序文件夹加入白名单。

四、若程序无法启动
  1. 确认已完整解压，而非直接在压缩包内运行
  2. 右键单击 LANLink.exe，选择「以管理员身份运行」
  3. 若弹出错误提示框，请将提示框中的日志文件路径所指向的
     startup.log 文件发送给开发者，其中记录了完整的失败原因

────────────────────────────────────────────────────────────
 二、创建房间（游戏运行于本机时使用）
────────────────────────────────────────────────────────────

一、点击「① 创建房间」

二、程序将自动完成以下工作，通常耗时 1 至 3 秒：
  · 探测本机公网 IP 地址
  · 尝试通过路由器 UPnP 自动放行 UDP 端口
  · 创建虚拟网卡并分配虚拟 IP 地址
  · 启动虚拟局域网内核

三、界面将显示邀请码，格式如下：
      113.133.208.7:41273#k7m2q9x3rt5vb6n
  同时显示对方 IP 地址、房间密钥及手机端所需的配置项。

四、点击「复制」并将邀请码发送至对方。

五、本机虚拟 IP 地址固定为 10.144.0.1。

────────────────────────────────────────────────────────────
 三、加入房间（游戏运行于对方本机时使用）
────────────────────────────────────────────────────────────

一、点击「② 加入房间」

二、粘贴对方提供的邀请码，点击「使用邀请码连接」

三、亦可选择「或：仅填写 IP 地址与房间密钥」，
  分别填写对方 IP 地址与 16 位房间密钥后点击「使用 IP 地址连接」

四、连接成功后，界面下方将显示绿色信息框，
  其中包含可直接用于游戏联机的虚拟 IP 地址。

────────────────────────────────────────────────────────────
 四、成员列表与虚拟 IP
────────────────────────────────────────────────────────────

成员列表每 2 秒自动刷新一次，格式如下：

    10.144.0.2   lanlink-DESKTOP   直连   0.44ms

  · 10.144.0.2　　该成员的虚拟 IP 地址
  · lanlink-DESKTOP　该成员的计算机名
  · 直连 / 中继　　链路类型，直连延迟最低
  · 0.44ms　　　　往返延迟

在游戏的「添加服务器」或「直连 IP」中填入对方虚拟 IP 地址即可联机。

注意：游戏服务端须监听 0.0.0.0，仅监听 127.0.0.1 将导致外部无法接入。
此为游戏自身的设置要求。

如需验证链路是否可用，请点击「测试连通性」。

────────────────────────────────────────────────────────────
 五、无法连接时的排查步骤
────────────────────────────────────────────────────────────

一、确认双方状态显示正常，且邀请码未被修改

二、确认安全软件未拦截程序或虚拟网卡驱动

三、由房间创建方点击「测试连通性」

四、确认「使用社区公共节点」已勾选（默认已勾选）
  勾选后程序会自动探测并挂载若干公开的共享节点。
  直连成功时走点对点直连（延迟最低，约 1 毫秒），
  直连失败时自动经公共节点转发（延迟约 100 至 400 毫秒）。
  此机制与 Radmin VPN 的「直连优先、中继兜底」一致，
  无需注册账号、无需自备服务器、无需改动路由器设置。

五、在路由器开启 UPnP（可选，可进一步降低延迟）
  登录路由器管理页，查找「UPnP」「自动端口映射」或「NAT 穿透」选项并开启。
  开启后路由器会自动将本机端口映射到公网，对方即可主动连接。

六、追加自定义共享中继节点（可选）
  在建房界面与加入界面的「追加共享中继节点」中填写地址，
  格式为 tcp://<中继服务器 IP>:11010，双方须填写同一地址。

七、收集诊断信息
  由房间创建方点击「复制诊断信息」，可将公网 IP、NAT 类型、端口映射状态、
  监听端口、成员列表与内核日志复制出来，便于进一步分析。

────────────────────────────────────────────────────────────
 六、安全与隐私
────────────────────────────────────────────────────────────

一、无需注册账号，无任何费用，不含广告，不上传任何数据

二、房间密钥每次创建房间时随机生成（16 位），房间之间相互隔离

三、传输流量由内核默认使用 AES-GCM 加密

四、点击「断开连接」后虚拟网卡自动移除，不影响本机正常上网

五、卸载方式为直接删除整个程序文件夹，系统不保留残留项

────────────────────────────────────────────────────────────
 七、技术信息
────────────────────────────────────────────────────────────

  协议内核　　EasyTier v2.6.4（Apache-2.0 开源，未作修改）
  虚拟网段　　10.144.0.0/24
  网络名称　　lanlink（固定值，房间隔离由密钥承担）
  房间主节点　10.144.0.1
  成员地址　　由密钥与本机指纹派生，范围 10.144.0.2 至 10.144.0.254
  监听端口　　每次创建房间时随机选取（20000-60000）
  共享中继　　社区公共节点（默认启用，直连失败时经其转发）
  传输方式　　点对点直连，失败时自动转为中继
  强制中继　　设环境变量 LANLINK_NO_P2P=1 可禁用直连，只走中继
  加密方式　　AES-GCM（内核默认启用）
  外部依赖　　无
