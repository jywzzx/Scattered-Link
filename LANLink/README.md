# LANLink · 异地局域网联机

不用注册、不装驱动、不要管理员权限。双击打开，把一串连接码发给朋友，他就进了你的"局域网"。

- **零第三方依赖** —— 只用 Node 内置模块，没有任何 npm 包
- **零账号** —— 没有注册、没有云端、没有遥测
- **零驱动** —— 端口级隧道，不装 TUN/TAP，不碰系统网络设置
- **只暴露一个端口** —— 白名单转发，朋友连不到你别的服务

---

## 一、它到底做了什么

```
你的电脑                                  朋友的电脑
┌──────────────┐                        ┌──────────────┐
│ 游戏服务端    │                        │ 游戏客户端    │
│ 127.0.0.1:   │                        │ 连 127.0.0.1: │
│   25565      │                        │   25565       │
└──────┬───────┘                        └──────▲───────┘
       │ 本地 TCP                              │ 本地 TCP
┌──────▼───────────────────────────────────────┴───────┐
│            UDP 隧道（IPv6 直连 / UPnP / 打洞）        │
└──────────────────────────────────────────────────────┘
```

朋友不需要理解任何网络概念：他只要在游戏里把服务器地址填 `127.0.0.1`，
流量就会被你的程序从公网那头接过来，送到你本机的游戏服务上。

## 二、电脑端（Windows / macOS / Linux）

### 1. 装 Node.js

需要 **Node.js 18 或更高**（推荐 20/22 LTS）：<https://nodejs.org>

装完在终端里 `node -v` 能看到版本号即可。

### 2. 启动

| 系统 | 操作 |
| --- | --- |
| Windows | 双击 `start.cmd` |
| macOS / Linux | `sh start.sh` |
| 任意 | `node src/main.js --open` |

浏览器会自动打开 `http://127.0.0.1:7788/`。
（如果 7788 被占用，会自动顺延到 7789、7790…，终端里会打印实际地址。）

### 3. 我做主机

1. 切到「我做主机」标签
2. 填**本地服务端口**（见下方对照表）
3. 点「启动主机」
4. 把界面上的 **连接码**（`LANL-...` 开头）复制发给朋友

启动时程序会自动做三件事，日志里能看到结果：

- 用 SSDP 找路由器，尝试 **UPnP 自动放行** UDP 端口
- 用 **IPv6** 找一个公网直连入口
- 用 **STUN** 探测公网映射，判断 NAT 是锥型还是对称型

界面上「可用入口」会列出所有打通的路，标注走的是哪条（`IPv6直连` / `UPnP` / `STUN` / `仅局域网`）。

### 4. 我加入

1. 切到「我加入」标签
2. 粘贴朋友发来的连接码
3. 点「连接」
4. 看到绿色的「连上了」，下面会告诉你本机该填的地址，例如 `127.0.0.1:25565`

打开游戏，服务器地址填这个就进去了。

> **端口被占用怎么办**：如果本机已经有程序占着 25565，程序会自动顺延到 25566 并提示你，
> 界面上显示哪个就用哪个。

## 三、手机端（Android）

手机端用的是同一套代码，靠 Termux 跑 Node，界面是 PWA（可以加到桌面当独立 App 用）。

```bash
# 1. 从 F-Droid 或 GitHub 安装 Termux
pkg update && pkg install nodejs -y

# 2. 把 project 目录拷到手机（数据线 / 网盘 / git 都行），然后
cd ~/LANLink
sh start.sh
```

首次运行会打印一个局域网地址，形如：

```
手机访问: http://192.168.1.23:7788/
```

在手机浏览器打开这个地址，然后 **菜单 → 添加到主屏幕** —— 之后就像原生 App 一样有图标。

> Termux 里 `start.sh` 无法调起浏览器时，手动在浏览器输入打印出来的地址即可。
> 想开机自启，可以装 Termux:Boot 并在 `~/.termux/boot/` 放一个启动脚本。

iOS 目前没有可行的本地 Node 运行环境，只能用电脑端。

## 四、常见游戏端口

| 游戏 | 协议 | 端口 |
| --- | --- | --- |
| Minecraft Java 版 | TCP | 25565 |
| 泰拉瑞亚 (Terraria) | TCP | 7777 |
| 星露谷物语 | TCP | 24642 |
| 饥荒联机版 | UDP | 10999 ❌ 本项目暂不支持 UDP |
| 帕鲁 / Rust / 方舟 | TCP+UDP | 需按游戏文档，UDP 部分不支持 |
| 求生之路2 / CS | UDP | ❌ 不支持 |

> 本项目当前只转发 **TCP**。判断方法：游戏服务器地址里如果只填 IP 不填端口，
> 或者官方文档写的是 TCP，就能用。写 UDP 的（如饥荒、基岩版 Minecraft）暂时不行。

## 五、连不上怎么办（按顺序排查）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 主机界面显示「仅局域网」 | 三条免费路径都没打通 | 进路由器管理页开启 **UPnP**；或打运营商客服要 **公网 IPv6**；换手机热点试试 |
| 显示「对称型 · 打洞难」 | 运营商级 NAT | 同上，优先解决 UPnP / IPv6 |
| 加入时「握手超时」 | 主机侧端口没通 | 确认主机仍在等待；确认双方没开 VPN/代理（会改路由）；关掉 Windows 防火墙里对该程序的拦截 |
| 连上了但游戏进不去 | 端口填错 | 主机填的是游戏**服务端口**，不是隧道的 UDP 端口；看界面上「本地服务端口」是否和游戏一致 |
| 连上后很卡 | 走了打洞/中继 | 看「联机方式」，`IPv6直连` 最快；`STUN` 次之 |
| 中文乱码（Windows） | 终端编码 | `start.cmd` 里已 `chcp 65001`，用 cmd 而非 PowerShell ISE 打开 |

防火墙放行（Windows，首次运行时如果没弹窗同意）：

```powershell
netsh advfirewall firewall add rule name="LANLink" dir=in action=allow program="C:\Program Files\nodejs\node.exe" enable=yes
```
