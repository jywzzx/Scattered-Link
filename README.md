# LANLink 联机助手

**无需注册 · 无需自备服务器 · 组建异地虚拟局域网**

LANLink 将不同网络环境下的设备接入同一个虚拟局域网。各成员在界面上看到彼此的虚拟 IP
地址，在任意支持局域网联机的游戏中直接填入对方虚拟 IP 即可联机，使用体验与
Radmin VPN 一致。

> **使用前请注意**：软件需创建虚拟网卡，运行时系统会请求管理员权限，
> 请选择「是」。若安全软件提示拦截，请选择「允许」并将整个文件夹加入白名单
> （虚拟网卡驱动 Wintun 是最常见的拦截对象）。

---

## 一、快速开始

1. 从 [Releases 页面](https://github.com/jywzzx/Scattered-Link/releases) 下载 `LANLink-v2.5.0-win64.zip`
2. 解压（**请勿直接在压缩包内运行**）
3. 双击 `LANLink.exe`，系统询问管理员权限时选择「是」
4. 房主点击「① 创建房间」，界面出现一行邀请码，复制发送给对方
5. 对方点击「② 加入房间」，粘贴邀请码后点击「使用邀请码连接」
6. 双方在游戏中填入对方的虚拟 IP 地址

压缩包内已自带 Java 运行环境，**对方无需安装任何软件**。同时包含手机端 APK。

### 成员列表

连接成功后，每 2 秒自动刷新：

```
10.144.0.2   lanlink-DESKTOP   直连   0.44ms
```

| 字段 | 含义 |
|---|---|
| `10.144.0.2` | 该成员的虚拟 IP 地址，**在游戏中填这个** |
| `lanlink-DESKTOP` | 该成员的计算机名 |
| `直连` / `中继` | 链路类型。直连延迟最低（约 1 毫秒），中继约 100-400 毫秒 |
| `0.44ms` | 往返延迟 |

房主的虚拟 IP 固定为 `10.144.0.1`。成员的虚拟 IP 由房间密钥与本机指纹派生，
同一台机器重连地址保持不变。

## 三、三个核心参数

界面建房后会显示三项内容，它们是**本次会话的凭据**，会话内保持不变：

| 参数 | 示例 | 说明 |
|---|---|---|
| 对方 IP 地址 | `113.133.208.7` | 公网出口地址，换网络后会变 |
| 监听端口 | `41273` | 每次建房随机选取（20000-60000） |
| 房间密钥 | `k7m2q9x3rt5vb6n` | 16 位随机字符，每次建房重新生成 |

邀请码格式：`IP:端口#密钥`

**房主必须保持程序运行**，对方才能接入。房主中途重新建房会导致对方掉线。

## 五、常见问题

**Q：程序双击后没反应 / 一闪而过？**

依次检查：① 是否已完整解压；② 是否以管理员身份运行；③ 安全软件是否拦截
（虚拟网卡驱动 Wintun 是最常见的拦截对象，需将整个文件夹加入白名单）。
若程序弹出错误提示框，其中会显示日志文件路径，可将该文件提供给开发者。

**Q：显示已连接，但成员列表是空的？**

说明链路尚未建立。可点「测试连通性」，并确认「使用社区公共节点」已勾选
（默认已勾选）。若双方网络为对称型 NAT 且路由器未开放端口，直连会失败，
此时程序会自动经公共节点转发，延迟略高但可用。

**Q：游戏里填了虚拟 IP 但连不上？**

游戏服务端须监听 `0.0.0.0`，仅监听 `127.0.0.1` 会导致外部无法接入。
这属于游戏自身的设置要求，与本软件无关。

**Q：手机端怎么用？**

压缩包内含 `手机端/LANLink-手机版.apk`。电脑端建房后点击「保存配置文件」
生成 `lanlink-phone.toml`，发送到手机后在手机端点「导入配置」即可。
注意手机端须取消勾选 DHCP，手动填写与电脑端同网段的 IPv4 地址。

## 六、技术说明

- 界面层：Java 17 + Swing，打包为独立 exe（jpackage app-image，自带 JRE）
- 网络内核：[EasyTier](https://github.com/EasyTier/EasyTier) v2.6.4（Apache-2.0），
  **未修改内核源码**，仅在外部做封装、诊断与错误翻译
- 手机端：EasyTier 官方 ARM64 APK（Apache-2.0），随包分发
- 房间隔离由 16 位随机密钥承担，网络名称固定为 `lanlink`
- 直连优先，打洞失败自动经社区公共节点中继兜底

详细文档见仓库内 `docs/` 目录。
